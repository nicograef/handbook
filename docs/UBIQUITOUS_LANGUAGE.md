# Ubiquitous language

## Research digest

| Term | Definition | Avoid |
| --- | --- | --- |
| Profile | The repo file naming a project's summary, lanes and report folder. | researcher agent, config |
| Lane | One topic area of a profile, swept by one researcher in parallel. | track, stream |
| Researcher | The subagent that sweeps one lane and returns story drafts. | reader, discovery agent |
| Story | One development told in the report: headline, source, summary, "for us" line. | item, finding |
| Sweep | A run over the profile's lanes, covering the last 30 days. | digest run, scan |
| Report | The markdown newsletter a run writes; the page renders it. | digest, issue |
